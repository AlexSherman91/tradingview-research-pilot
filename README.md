# Исследовательская тетрадь — концепт пилота

[Открыть прототип](https://AlexSherman91.github.io/tradingview-research-pilot/)

Шесть экранов: цель → план → факты → сравнение → аргументы за и против → собственный вывод.

Концепт для продуктового кейса, не текущий интерфейс TradingView. Навигация между экранами работает; ввод и сохранение данных не реализованы. Иллюстративные записи не являются инвестиционным анализом или рекомендацией.
