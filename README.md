# Research notebook — pilot concept

[Open the prototype](https://alexsherman91.github.io/tradingview-research-pilot/)

Entry point: **Products → Research notebook · Pilot** in the top navigation.

Six steps: research goal → research plan → facts and sources → compare data → arguments and risks → my conclusion.

The homepage and notebook use visual conventions from the TradingView website. This is a product case concept, not the current TradingView interface. The full interface is in English. Navigation works; editing and saving data are not implemented. Illustrative entries are not investment research or recommendations.

Direct links `?step=1` through `?step=6` remain supported.

[Overview of all six steps](https://alexsherman91.github.io/tradingview-research-pilot/overview.html)

The homepage background video and poster are loaded from TradingView’s public asset CDN. The Financials image is an original TradingView screenshot from the interface audit.
